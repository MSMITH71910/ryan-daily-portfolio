## 📸 Overview

This is a fully responsive, single-page portfolio website designed for **Ryan Daily**, a General Creative Professional. The site showcases work, skills, and contact information with a sleek dark cinematic aesthetic — and includes an interactive AI-style chatbot assistant.

Built with **zero frameworks** — pure HTML, CSS, and vanilla JavaScript for maximum performance and zero dependencies.

---

## ✨ Features

| Feature | Details |
|---|---|
| 🎬 **Cinematic Hero** | Full-screen animated gradient orbs, large serif typography |
| 👤 **About Section** | Bio, experience stats, photo frame with accent badge |
| 🎭 **Work Portfolio** | 5 featured project cards with hover effects and categories |
| 🛠️ **Skills Grid** | 6 skill cards with smooth hover animations |
| 📩 **Contact Form** | Form with popup confirmation modal on submission |
| 💬 **AI Chatbot** | Interactive chatbot with FAQ, contact guidance, and jokes |
| 📱 **Fully Responsive** | Optimized for mobile, tablet, and desktop |
| ⚡ **Zero Dependencies** | No frameworks, no npm — just HTML, CSS & JS |

---

## 🤖 Chatbot Capabilities

The built-in **RD Bot** assistant can:

- Answer questions about Ryan's background and experience
- Describe featured work and projects
- Provide contact and booking information
- Share availability and rate inquiry guidance
- Tell jokes on demand 😄

## 🚀 Getting Started

No build tools or dependencies required.

**Option 1 — Open directly:**
```bash
# Clone the repo
git clone https://github.com/MSMITH71910/ryan-daily-portfolio.git

# Open in your browser
open ryan-daily-portfolio/index.html
```

**Option 2 — Live server (recommended for development):**
```bash
# Using VS Code Live Server extension, or:
npx serve ryan-daily-portfolio
```

## 🎨 Customization Guide

| What to change | Where |
|---|---|
| Your name & bio | `index.html` → About section |
| Profile photo | Replace the SVG placeholder in `index.html` with an `<img>` tag |
| Featured work cards | `index.html` → Work section |
| Skills | `index.html` → Skills section |
| Contact email | `index.html` → Contact section & footer |
| Color theme | `style.css` → `:root` CSS variables |
| Chatbot responses | `script.js` → `responses` array |
